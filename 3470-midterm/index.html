Style Queries

and the great things you can do with them

What are Style Queries?

Style Queries are a feature of container queries, which are used to apply certain styles to elements inside its parent, responding to size. Style queries are one step above it, as it lets developers now apply styles to child elements with its container, defined by the “style()” notation within the @container rule. It makes theming a lot more straightforward and gives developers the ability to reuse cards in a much more flexible manner. And the best part: it requires no JavaScript!

This essentially means:
"If the container has --theme: happy, the following classes within the container have these styles applied".

Why Style Queries?

It's an easier and more powerful way to transform your pages. For example, the interactive aspect of the hero was made with the custom property “--theme” with some simple JavaScript only being utilized for assigning functions to the buttons. *Include all possible elements inside the card’s HTML, such as a sale badge, a popularity icon, and the sale price. Make sure these elements are hidden by default using CSS so that they do not appear on every card.
*Each card is then set as a style container using ‘container-type: style’, and a custom variable like ‘--card-style' is applied to indicate the card’s context. Style queries can then detect this variable and selectively reveal or modify elements within the card.

With this, the card components can adapt its appearance automatically based on the style context it is placed in, demonstrating how style queries help create flexible and reusable UI components with just a few lines of code!!
